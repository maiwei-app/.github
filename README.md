# .github

Org-wide community health defaults for `maiwei-app`. Applies to any repository
in the org that doesn't define its own copy of these files.

| File | Purpose |
|---|---|
| `PULL_REQUEST_TEMPLATE.md` | Default PR template |
| `ISSUE_TEMPLATE/` | Default issue templates (bug report, feature request) |
| `CODEOWNERS` | Default code owner |
| `SECURITY.md` | Vulnerability reporting policy |

Reusable workflows live in a separate repo: `maiwei-app/workflows`.
